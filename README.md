# 🍳 Recipe Corner — Food Recipes Web Platform

A multi-page web application dedicated to exploring everyday recipes, meal ideas, culinary tips, and kitchen guides across multiple meal categories.

---

## 📌 Project Note & Status

> **⚠️ Work in Progress / Learning Project:**  
> This is my **first-ever project built using pure HTML5 and CSS3**[cite: 1, 2]. Because it is a beginner learning project and currently **unfinished**, there might be some small bugs, styling inconsistencies, or missing features (*kamiyan*). I am actively learning and continuously working to refine the codebase!

---

## ✨ Key Features & Highlights

* **Categorized Meal Hubs:** Dedicated pages for Breakfast, Lunch, Dinner, and Desserts with curated recipe cards[cite: 1, 2].
* **Real-Time Client-Side Search:** Instant search engine (`search.html`) that queries recipes by title, ingredient, or category without page reloads[cite: 1, 2].
* **Culinary Blog & Details View:** An integrated blog section (`blog.html`) and dedicated long-form article view (`blog-details.html`) for kitchen hacks and baking guides[cite: 1, 2].
* **Responsive Layouts:** Built using CSS Grid and Flexbox with media queries for mobile, tablet, and desktop screens[cite: 1, 2].
* **Contact Channel:** A structured contact page (`contact.html`) featuring a message form and reach-out details[cite: 1, 2].
* **Zero External Dependencies:** Built with pure vanilla HTML5, CSS3, and JavaScript[cite: 1, 2].

---

## 🛠️ Technology Stack

* **HTML5:** Semantic page structuring (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`)[cite: 1, 2].
* **CSS3:** Custom layouts using Flexbox, CSS Grid, and media query breakpoints[cite: 1, 2].
* **JavaScript:** Client-side array filtering for the search bar.
